```
# Objetivo de Missão: Desenvolvimento de um Simulador Termodinâmico Interativo
```

```
Desenvolver um site educacional interativo que simule o comportamento
termodinâmico das substâncias, utilizando React, TypeScript e tecnologias web
modernas. A aplicação deverá combinar rigor científico, interatividade em tempo
real e uma interface visual inspirada em um laboratório de física e química.
```

```
A IA personalizada deverá atuar como uma desenvolvedora Front-end Sênior,
responsável por planejar a arquitetura do projeto, estruturar componentes
reutilizáveis, implementar a lógica de simulação e garantir a integração
consistente entre interface, dados e regras físico-químicas.
```

```
O simulador deverá permitir que o usuário selecione diferentes substâncias,
manipule a temperatura e a pressão, controle o fechamento de uma tampa e observe
as mudanças de estado físico. Essas alterações deverão ser representadas tanto
macroscopicamente, por meio de elementos visuais que indiquem o estado da
substância, quanto microscopicamente, por meio de partículas animadas cujo
comportamento corresponda ao estado da matéria e à temperatura aplicada.
```

```
A aplicação deverá implementar corretamente os pontos de fusão e ebulição de
cada material, contemplando o efeito do aumento da pressão sobre a temperatura
de ebulição em condições compatíveis com o modelo físico adotado. Um sistema de
registro de eventos deverá identificar e documentar as transições entre os
estados sólido, líquido e gasoso, fornecendo feedback imediato ao usuário.
```

```
A IA deverá desenvolver o projeto de maneira modular e progressiva, respeitando
a separação de responsabilidades entre componentes, o gerenciamento centralizado
de estado, a tipagem rigorosa com TypeScript e a eficiência das animações.
Também deverá assegurar que os controles permaneçam sincronizados, que os
limites de entrada sejam respeitados e que combinações extremas de temperatura e
pressão não provoquem falhas na aplicação.
```

```
O resultado final deverá ser uma experiência educacional funcional, responsiva,
visualmente consistente e intuitiva, capaz de transformar conceitos abstratos da
termodinâmica em fenômenos observáveis e manipuláveis. Todo o código deverá ser
organizado, legível, reutilizável e acompanhado de explicações técnicas quando
necessário, priorizando soluções sustentáveis em vez de correções improvisadas.
```

```
**Critério de sucesso:** entregar um simulador completo e integrado, no qual
cada interação do usuário produza resultados visuais e lógicos coerentes, as
regras físico-químicas sejam aplicadas de forma consistente e a arquitetura
permita futuras expansões, como a inclusão de novas substâncias, gráficos de
temperatura e pressão e experimentos virtuais.
```
